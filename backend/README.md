# Законодавство України API

Бекенд сервіс для пошуку та фільтрації законів України. 
Дані парсяться з офіційного сайту Верховної Ради (zakon.rada.gov.ua) 
і зберігаються в PostgreSQL базі даних (Supabase).

## Технології
- **FastAPI** — веб фреймворк
- **SQLAlchemy** — ORM для роботи з БД
- **Alembic** — міграції БД
- **PostgreSQL** (Supabase) — база даних
- **httpx + BeautifulSoup** — парсинг сайту

## База даних і моделі

Проект використовує три таблиці з відношенням many-to-many між законами і категоріями.

### laws
Зберігає інформацію про закони:
- `id` — первинний ключ
- `rada_id` — унікальний ідентифікатор з сайту (напр. `2341-IX`)
- `title` — назва закону
- `number` — номер закону
- `date_adopted` — дата прийняття
- `status` — статус (Чинний / Скасований)
- `url` — посилання на закон на zakon.rada.gov.ua

### categories
Фіксований список з 28 категорій юридичної класифікації:
- `id` — первинний ключ
- `name` — повна назва (напр. "Трудове законодавство")
- `slug` — числовий код категорії (напр. "50")

### law_categories
Таблиця зв'язку між `laws` і `categories`.
Один закон може належати до кількох категорій, одна категорія містить багато законів (many-to-many).
- `law_id` — зовнішній ключ на `laws`
- `category_id` — зовнішній ключ на `categories`

## Парсер

Скрипт `app/parser/parser.py` збирає дані з zakon.rada.gov.ua і зберігає в БД.

### Як працює

Парсинг відбувається по категоріях — для кожної з 28 категорій 
проходимо всі сторінки списку законів.

URL сторінки категорії:
- Перша: `https://zakon.rada.gov.ua/laws/main/klas10/page`
- Друга: `https://zakon.rada.gov.ua/laws/main/klas10/page2`

### Три функції

**`fetch_page(url)`** — завантажує HTML сторінки через httpx.
Відправляє запит з заголовком User-Agent щоб сервер не блокував запити.

**`parse_laws(html)`** — парсить HTML через BeautifulSoup.
Для кожного закону витягує: назву, url, дату, номер, статус, rada_id.

**`save_laws(laws, slug)`** — зберігає список законів в БД.
Для кожного закону також знаходить категорію по slug і створює 
запис в таблиці `law_categories`.

### Запуск

```
python3 -m app.parser.parser
```

## API ендпоінти

Документація доступна за адресою `http://localhost:8000/docs` після запуску.

### GET /laws/
Повертає список законів з опціональними фільтрами.

**Параметри:**
| Параметр | Тип | Опис |
|----------|-----|------|
| `category` | enum | Категорія закону (освіта, оборона...) |
| `status` | string | Статус закону (напр. "Чинний") |
| `search` | string | Пошук по назві закону |
| `offset` | int | Пропустити N записів (дефолт: 0) |
| `limit` | int | Максимум записів у відповіді (дефолт: 50) |


### GET /laws/{rada_id}
Повертає один закон по його унікальному ідентифікатору.

## Сервіси

`app/services/laws_service.py` містить клас `LawsService` з бізнес логікою.
Роутер створює екземпляр класу з сесією БД і викликає методи.

### LawsService

**`get_laws(category, status, search, offset, limit)`**
Будує SQLAlchemy запит з фільтрами:
- `search` — фільтр через `ilike` (пошук без урахування регістру)
- `status` — точне співпадіння
- `category` — JOIN через `law_categories` до `categories` по slug
- `offset` і `limit` — пагінація результатів

**`get_law_by_id(rada_id)`**
Повертає один закон по `rada_id` або `None` якщо не знайдено.
